# Moon Palace · Web beta 0.24.09

Open: https://cpfortune1111.github.io/palace-web-beta/Web-beta/0.24.09/online.html?revision=effects1

Online browser trial. HTML/JavaScript/CSS are public; media/data are AES-256-GCM encrypted and automatically decrypted. All dependencies stay inside the release folder. No mandatory offline download or persistent storage permission.

Character Select includes a collapsible Effects / Performance HUD: 13 independent switches, All on/off, UI and 3D FPS. Effects initially off for diagnosis.

Battle Loading prepares both selected fighters' sprite frames, sounds, engine code and required battle resources before combat. Common effects reuse prepared bitmaps; sounds reuse decoded buffers. Non-battle presentation preparation is deferred until combat ends. Mobile prepared copies use a memory budget and may be resampled; editable originals remain preserved privately.

On iPhone: Safari → Share → Add to Home Screen. On Android: browser menu → Install app / Add to Home Screen. Internet required.

Automatic client-side decryption is not DRM or guaranteed extraction prevention. Original sources, snapshots and private build inputs are maintained separately.
